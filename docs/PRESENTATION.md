# SocPulse — цифровая платформа управления территориями

## Решение для оптимизации рабочих процессов Управления по развитию сельскими территориями

---

## Проблема

Управление по развитию сельскими территориями г.о. Мытищи ежедневно работает с большим потоком данных из разрозненных источников:

- **Обращения граждан** из ЕЦУР (Добродел, ППМО, Инцидент, ПОС, ЕДС) — сотни обращений в месяц без единой аналитики
- **Отсутствие оперативной картины** — какие проблемы критичны, где горячие точки, какова динамика
- **Ручной мониторинг соцсетей** — жалобы жителей в Telegram-чатах остаются незамеченными до эскалации
- **Разрозненные KPI** — показатели эффективности не собраны в единую систему, нет визуализации прогресса
- **Контроль выхода на линию** — ежедневный учёт сотрудников ведётся вручную

---

## Решение: платформа SocPulse

Единая цифровая платформа, объединяющая все ключевые процессы управления в одном интерфейсе с AI-аналитикой.

### Модуль 1. Дашборд KPI

**Автоматический расчёт ключевых показателей из данных ЕЦУР:**

| Показатель | Что измеряет | Источник |
|---|---|---|
| Индекс социального напряжения (ИСН) | Эмоциональный окрас обращений граждан | AI-анализ текстов обращений |
| Обращений на 1000 жителей | Интенсивность обращений относительно населения | ЕЦУР + Росстат |
| Горячие адреса | Доля обращений с повторяющихся адресов | Автоматическая группировка |
| Отложенные обращения | Доля обращений со статусом «закрыта с отложенным» | ЕЦУР |

**Возможности:**
- Переключение периодов: неделя / месяц / квартал / год
- Radar-диаграмма исполнения всех KPI с цветовой индикацией
- Drill-down: клик на показатель → детализация → конкретное обращение
- Горячие адреса: карточная визуализация проблемных точек с раскрытием обращений
- Целевые значения KPI (D90 / D180 / D360) настраиваются администратором

### Модуль 2. Индекс социального напряжения (ИСН)

**AI-анализ эмоционального окраса каждого обращения:**

- Автоматическая оценка по шкале 1–10 через нейросеть DeepSeek
- Светофорная система: штатный режим / внимание / эскалация
- Гистограмма распределения с drill-down по баллам
- Критические обращения (9–10) — моментальное копирование для Telegram-рассылки руководству
- Модерация: ручная корректировка балла, исключение спама
- Few-shot калибровка: отмодерированные примеры улучшают точность AI

### Модуль 3. Мониторинг Telegram-чатов

**Автоматический сбор и AI-анализ сообщений из гражданских чатов:**

- Бот 24/7 слушает подключённые Telegram-чаты жителей
- Каждые 30 минут AI анализирует поток сообщений:
  - Отсеивает мусор (приветствия, спам, личные разговоры)
  - Группирует сообщения в тематические ветки (проблемы)
  - Оценивает критичность каждой проблемы (1–10)
  - Извлекает адрес, тему, ключевые цитаты
- Алерты: проблемы с оценкой ≥ 9 автоматически эскалируются
- Управление статусами: новая → на контроле → эскалация → решена
- Раздельный анализ по каждому чату

**Пример работы:**
> В чате «Мытищи Пироговский» 6 жителей обсуждают яму на ул. Центральной у д.15. Один прикладывает фото, другой пишет «третий раз за месяц, никакой реакции», третий предлагает коллективную жалобу в прокуратуру.
>
> **Результат AI:** Проблема «Разбитая дорога», score 8/10, тема «дороги», адрес «п. Нагорное, Центральная ул., д. 15». Рекомендация: эскалация.

### Модуль 4. Управление обращениями

- Импорт выгрузок XLSX из ЕЦУР в один клик
- Автоматическая дедупликация по номеру ЕЦУР
- Фильтрация по направлению, статусу, периоду
- Карточка обращения с полной информацией + ссылка на Добродел
- Автозапуск AI-анализа после каждого импорта

### Модуль 5. Контроль выхода на линию (Яндекс Вектор)

- Ежедневный учёт факт/план выхода сотрудников МБУ «МТХ»
- Целевой показатель 85%
- Визуализация по дням, месяцам, кварталам, году
- Цветовая индикация: зелёный (≥85%) / жёлтый (70–84%) / красный (<70%)
- Исторические данные за весь год

## Технологический стек

| Компонент | Технология | Назначение |
|---|---|---|
| Веб-интерфейс | React + TypeScript | SPA-приложение, работает в браузере |
| База данных | Supabase (PostgreSQL) | Облачная БД с API, без администрирования |
| AI-анализ | DeepSeek API | Оценка эмоций, классификация проблем |
| Telegram-бот | Python + Telethon | Сбор сообщений из чатов 24/7 |
| Хостинг | VPS + Nginx | Доступ по адресу socpulse.ru |

## Результаты

### До внедрения
- Ручной анализ обращений — часы работы специалиста
- Проблемы в соцсетях обнаруживаются постфактум
- KPI отслеживаются в Excel без визуализации
- Нет единой картины по территории

### После внедрения
- **Автоматический расчёт KPI** из данных ЕЦУР — секунды вместо часов
- **Раннее обнаружение проблем** через мониторинг Telegram-чатов
- **AI-приоритизация** — критичные обращения выявляются автоматически
- **Единый дашборд** — вся аналитика в одном окне
- **Оперативная эскалация** — копирование критических обращений для руководства в один клик

---

## Масштабирование

Платформа спроектирована для расширения:

- Подключение дополнительных Telegram-чатов — через интерфейс, без разработки
- Новые KPI-показатели — добавляются в настройках
- Дополнительные модули (кадры, дорожная карта, территории) — готовы, активируются по необходимости
- Интеграция с другими источниками данных (Госуслуги, порталы обратной связи)
